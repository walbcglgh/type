# 打字練習（Type Practice）

純靜態的電腦打字練習網頁，中英文皆可，並附上台灣標準注音鍵盤的鍵位學習模式。
無框架、無構建步驟、無後端，直接把資料夾推上 GitHub Pages 就能跑，之後要搬 Vercel 也不用改程式碼。

## 使用

開啟網頁即可，不需要安裝任何東西。

採四頁流程，一步一步確認後才開始打字：

```
首頁（選模式）→ 設定頁（確認該模式的選項）→ 練習頁 → 結果頁
```

- 練習頁頂部有一列當輪設定摘要，旁邊「修改」可回設定頁；按 `Esc` 同樣回設定頁，並停止這輪計時。
- 結果頁有三個出口：**再練一次**（同設定）、**換設定**、**回首頁**。
- 網址列以 `#/`、`#/setup`、`#/practice`、`#/result` 路由，瀏覽器上一頁／下一頁可正常前後走。
- 模式與所有設定會存在瀏覽器 localStorage，下次開來幫你還原。

### 一般練習

看文本打字，程式只比對字元，不干涉你使用哪種輸入法。

中文輸入的處理方式（重點）：

- 程式**不攔截按鍵**，注音、倉頡、嘸蝦米等輸入法照常運作 —— 選字、空格換字、Enter 確認全部交給系統。
- 你正在拼的注音會**顯示在游標處**（藍色虛線底），例如「ㄅㄧˇ」，確認成字後才消失，所以不會不知道自己打了什麼。
- 計分只取輸入法**確認後的成品**，組合中的拼音不計分、也不會被誤判成錯字。
- 隱藏的輸入框會跟著游標移動，輸入法的**選字窗就出現在你正在打的地方**，不會跑到螢幕角落。

| 選項 | 說明 |
| --- | --- |
| 素材 | **中文**（現代短句）、**唐詩**（御定全唐詩，見下方）或**英文**（比對字母，請切到 English 輸入法）。中文與唐詩都只比對字元，可用注音／倉頡等任何輸入法 |
| 唐詩難度 | 易／中／難，依全篇最冷門字的出現頻率分級 |
| 計量方式 | **計時**：時間到就結束，文本會自動接續；**計字**：打完整篇就結束 |
| 秒數 | 15 / 30 / 60 / 120（僅計時模式） |
| 打錯時 | **可繼續往下打**：錯字留紅並累計；**要改對才能繼續**：卡住直到退格修正 |
| 自訂文本 | 貼自己的文章來練，會自動判中英文並改用計字模式 |

選唐詩時，題目開頭會以藍色小字標示出處（作者與篇名），它只是提示、不參與比對。

結束後的四項數據：速度（中文為 字/分，英文為 WPM）、正確率、**打錯字數**、打對字數。

快捷鍵：`Esc` 回設定頁（停止這輪）、`⌫` 修正。

### 注音鍵位學習

螢幕出一個注音符號，你按對應的實體鍵。

- 按對 → 綠燈，自動出下一題。
- 按錯 → 紅燈閃爍並提示，**留在原題**直到按對，錯誤會計數。
- 完成一輪後顯示：答對率、平均反應時間、按錯次數、答對題數。

可選練習範圍：全部（42 鍵）／聲母（21）／介音（3）／韻母（13）／聲調（5）。
**黃色提示**開關：開著是認鍵位，關掉才是真的測驗。

下方鍵盤同時標示英文、Shift 符號與注音，並高亮下一個該按的鍵。

## 鍵位依據

採用**大千傳統**排列，也就是 Windows / macOS 內建注音輸入法的標準布局，與市售「中文/英文 注音鍵盤貼紙」相同：

```
1=ㄅ 2=ㄉ 3=ˇ 4=ˋ 5=ㄓ 6=ˊ 7=˙ 8=ㄚ 9=ㄞ 0=ㄢ -=ㄦ
q=ㄆ w=ㄊ e=ㄍ r=ㄐ t=ㄔ y=ㄗ u=ㄧ i=ㄛ o=ㄟ p=ㄣ
a=ㄇ s=ㄋ d=ㄎ f=ㄑ g=ㄕ h=ㄘ j=ㄨ k=ㄜ l=ㄠ ;=ㄤ
z=ㄈ x=ㄌ c=ㄏ v=ㄒ b=ㄖ n=ㄙ m=ㄩ ,=ㄝ .=ㄡ /=ㄥ
Space = 一聲（空白調）
```

共 37 個注音符號 + 5 個聲調 = 42 鍵。若你手上的鍵盤是許氏、倚天等其他排列，
只需修改 `js/data.js` 裡的 `BOPOMOFO` 這一處，鍵帽顯示與出題會一起跟著變。

## 唐詩素材

來自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 的《御定全唐詩》。幾個處理上的重點：

- **本來就是繁體**。該 repo 多數檔案是簡體，但《御定全唐詩》是清代刻本語料，原文即繁體，所以不需要繁簡轉換。
- 只做**異體字正規化**（`爲→為`、`峯→峰`、`裏→裡`），用 OpenCC 的 `t→tw`。刻意不用 `cn→tw`，因為那會把詩中本字改錯 —— 例如「余」在詩裡多是「我」、「里」是里程、「后」是皇后，不該變成「餘／裡／後」。
- 篩選條件：五言或七言規整、全篇每個字都是常用字（跨首出現率 ≥ 250）、20~56 字、去重。從 42,730 首留下 522 首（易 196／中 177／難 149），涵蓋約 240 位作者。
- 另濾掉結尾停在「，」的 8 首 —— 刻本段落有截斷，拿來當題目會讓人懷疑自己。
- 會淘汰掉《江雪》（蓑笠）、《楓橋夜泊》（姑蘇）這類名篇 —— 生僻字對打字練習是挫敗來源，寧可不收。
- 部分詩句與現在課本常見版本不同，例如《靜夜思》此本作「床前看月光／舉頭望山月」，是刻本原貌，不是錯字。

## 檔案結構

```
index.html      入口，直接開也能用
css/style.css   樣式（深/淺色主題）
js/data.js      鍵位表、出題範圍、詞庫句庫
js/poems.js     唐詩文本庫（522 首，約 80KB／gzip 37KB）
js/app.js       主邏輯
test/e2e.js     Playwright 端到端測試
```

## 本地開發與測試

```bash
# 直接開檔就能用
open index.html

# 跑測試（需要 playwright）
node test/e2e.js
```

測試涵蓋 15 組情境：四頁路由與可見性、選項互動與摘要、設定持久化、
真實按鍵路徑（英文直接打、注音組字不計分、Enter 不判錯、組字緩衝顯示）、
IME 輸入、錯誤累計與退格、嚴格模式卡住與解鎖、計字打完進結果頁、
再練一次／換設定／回首頁、瀏覽器前後頁、自訂文本、
學習模式答對/答錯與提示開關、範圍切換、跑完整輪、唐詩與英文素材、
深連結與未知路由、手機寬度響應式。截圖輸出到 /tmp/w-*.png。

## 已知限制

- 學習模式測的是「注音符號 ↔ 物理按鍵」的對應，不做選字，也不做拆字（倉頡未實作）。
- 打對率只統計字元層級，不記錄每字的錯誤分佈。
- 成績只存在瀏覽器 localStorage（存的是主題與練習設定，成績尚未持久化）。
