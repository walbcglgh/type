# 打字練習（Type Practice）

純靜態的電腦打字練習網頁，中英文皆可，並附上台灣標準注音鍵盤的鍵位學習模式。
無框架、無構建步驟、無後端，直接把資料夾推上 GitHub Pages 就能跑，之後要搬 Vercel 也不用改程式碼。

## 使用

開啟網頁即可，不需要安裝任何東西。

### 一般模式

看文本打字，程式只比對字元，不干涉你使用哪種輸入法。

| 選項 | 說明 |
| --- | --- |
| 語言 | 中文（比對字元，可用注音／倉頡等任何輸入法）或英文（比對字母，請切到 English 輸入法） |
| 計量方式 | **計時**：時間到就結束，文本會自動接續；**計字**：打完整篇就結束 |
| 秒數 | 15 / 30 / 60 / 120（僅計時模式） |
| 打錯時 | **可繼續往下打**：錯字留紅並累計；**要改對才能繼續**：卡住直到退格修正 |
| 自訂文本 | 貼自己的文章來練，會自動判中英文並改用計字模式 |

結束後的四項數據：速度（中文為 字/分，英文為 WPM）、正確率、**打錯字數**、打對字數。

快捷鍵：`Esc` 重新開始、`⌫` 修正。

### 學習模式

螢幕出一個注音符號，你按對應的實體鍵。

- 按對 → 綠燈，自動出下一題。
- 按錯 → 紅燈閃爍並提示，**留在原題**直到按對，錯誤會計數。
- 完成一輪後顯示：答對率、平均反應時間、按錯次數、答對題數。

可選練習範圍：全部（42 鍵）／聲母（21）／介音（3）／韻母（13）／聲調（5）。
**黃色提示**開關：開著是認鍵位，關掉才是真的測驗。

下方鍵盤同時標示英文、Shift 符號與注音，並高亮下一個該按的鍵。

## 鍵位依據

採用**大千傳統**排列，也就是 Windows / macOS 內建注音輸入法的標準布局，與市售「中文/英文 注音鍵盤貼紙」相同：

```
1=ㄅ 2=ㄉ 3=ˇ 4=ˋ 5=ㄓ 6=ˊ 7=˙ 8=ㄚ 9=ㄞ 0=ㄢ -=ㄦ
q=ㄆ w=ㄊ e=ㄍ r=ㄐ t=ㄔ y=ㄗ u=ㄧ i=ㄛ o=ㄟ p=ㄣ
a=ㄇ s=ㄋ d=ㄎ f=ㄑ g=ㄕ h=ㄘ j=ㄨ k=ㄜ l=ㄠ ;=ㄤ
z=ㄈ x=ㄌ c=ㄏ v=ㄒ b=ㄖ n=ㄙ m=ㄩ ,=ㄝ .=ㄡ /=ㄥ
Space = 一聲（空白調）
```

共 37 個注音符號 + 5 個聲調 = 42 鍵。若你手上的鍵盤是許氏、倚天等其他排列，
只需修改 `js/data.js` 裡的 `BOPOMOFO` 這一處，鍵帽顯示與出題會一起跟著變。

## 檔案結構

```
index.html      入口，直接開也能用
css/style.css   樣式（深/淺色主題）
js/data.js      鍵位表、出題範圍、詞庫句庫
js/app.js       主邏輯
test/e2e.js     Playwright 端到端測試
```

## 本地開發與測試

```bash
# 直接開檔就能用
open index.html

# 跑測試（需要 playwright）
node test/e2e.js
```

測試涵蓋 18 組情境：載入、IME 輸入、錯誤累計與退格、嚴格模式卡住與解鎖、
學習模式答對/答錯流程、提示開關、範圍切換、跑完整輪、英文模式、自訂文本、
主題持久化、Esc 重來、手機寬度響應式。

## 部署（自行處理）

GitHub Pages：Settings → Pages → Source 選分支與 `/ (root)` 即可。
Vercel：直接匯入 repo，Framework preset 選 **Other**，Build command 留空。

## 已知限制

- 學習模式測的是「注音符號 ↔ 物理按鍵」的對應，不做選字，也不做拆字（倉頡未實作）。
- 打對率只統計字元層級，不記錄每字的錯誤分佈。
- 成績只存在瀏覽器 localStorage（目前僅主題偏好有存，成績尚未持久化）。
